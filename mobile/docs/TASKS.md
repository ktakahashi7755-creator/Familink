# Familink Mobile — 品質向上タスクボード

目標品質（北極星）:
- **Apple 純正アプリレベル**の操作感・余白・タイポ・モーション
- **TimeTree を超える家族カレンダー体験**
- **iPhone 写真アプリ品質のアルバム**
- **OpenAI API 対応 Hoku エージェント**

優先度: **S**=体験の核 / **A**=公開前に必須 / **B**=公開後改善 / **C**=将来。
状態: ☐ 未着手 / ◐ 着手中 / ☑ 完了。

---

## 0. 基盤・全体磨き込み（S）
- ☑ ハイドレーションゲート（ストア復元まで起動スプラッシュ維持・チラつき防止）
- ☑ Haptics ユーティリティ（タップ/成功/警告の触覚）
- ☑ 確認ダイアログ / ボトムシート共通化（削除は二段階確認 §13.6）
- ☑ テーマ設定（システム連動／ライト固定／ダーク固定の手動切替）
- ☑ デモ初期データ投入（初回に家族と予定サンプル・空っぽ回避、設定で消去可）
- ☑ アニメーション基盤（reanimated：PressableScale 押下・Hoku 呼吸・ズーム）
- ◐ アクセシビリティ（Button/FAB/主要 Pressable に role/label・最小48pt。Dynamic Type 追従は今後）
- ☑ ダークモード整合（ナビゲーションヘッダー・画面背景をテーマ連動）
- ☑ 触覚フィードバック横断（追加/トグル/ナビゲーション/削除確認）

## 1. カレンダー（TimeTree 超え）（S）
- ☑ 月 / 週 / 予定リスト（アジェンダ）のビュー切替
- ☑ メンバー色フィルター（表示メンバーの絞り込み）
- ☑ 繰り返し予定の展開（daily/weekly/monthly/yearly を各ビューで反映）
- ☑ 複数日（期間）予定：セル横断のスパン帯をレーン詰めで描画
- ☑ 今日へ戻る + 月送り + 左右スワイプ（Fling）+ Haptics
- ☑ 祝日表示（日本の祝日 2025–2027・赤字＋日付ビューに名称）
- ☐ 予定への家族リアクション / コメント（共有体験）

## 2. アルバム（iPhone 写真アプリ品質）（A）
- ☑ 日付セクション分け（月ごとの見出し）
- ☑ フルスクリーンビューア（左右スワイプでページング・ピンチズーム・ダブルタップ）
- ☑ フォルダ / アルバム：作成・絞り込み・選択写真の移動 UI
- ☑ カメラ撮影で追加
- ☑ 複数選択 → まとめて削除 / フォルダへ移動
- ☑ 共有（端末の共有シート）／お気に入り（ハート・専用フィルター）

## 3. Hoku（OpenAI エージェント）（S）
- ☑ タイピングインジケータ・吹き出しの磨き込み
- ☑ 全 intent の追加アクション対応（予定/タスク/買い物/家計/体調/お知らせ/準備）
- ☑ 文脈に応じたクイック提案
- ☑ Hoku アバター（常駐感・呼吸アニメ）
- ☐ 直近の操作を踏まえた先回り提案（ホームに Hoku の一言）

## 4. 未移植画面の追加（A）
