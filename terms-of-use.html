Familink 利用規約

最終更新日：2026-05-16 / 草案 v0.2 ／ 事業者：ktakahashi7755-creator（個人開発）

第1条（目的）

本規約は、Familink（以下「本アプリ」）の利用条件を定めるものです。本アプリをご利用の方（以下「利用者」）は、本規約に同意したものとみなします。

第2条（本アプリの内容）

本アプリは、家族間での予定・タスク・体調・家計・準備リスト・家族ボードの管理を支援するツールです。すべてのデータは利用者の端末内（LocalStorage）に保存され、外部サーバには送信されません。詳細はプライバシーポリシーをご覧ください。

第3条（利用料金）

  1. 本アプリの基本機能は 無料 でご利用いただけます。
  2. 一部機能（Familink プレミアム）は将来、月額 480 円（予定）の有料プランとして提供を予定しています。
  3. 有料プランの料金・内容・提供開始時期は、事前告知のうえ変更する場合があります。

第4条（禁止事項）

利用者は、本アプリの利用にあたり、以下の行為を禁止します：

  1. 法令または公序良俗に違反する行為
  2. 本アプリのリバースエンジニアリング、改変、再配布
  3. 本アプリの動作を妨げる行為
  4. 他の利用者・第三者の権利を侵害する行為
  5. 本アプリを商用目的で第三者に転用する行為
  6. その他、開発者が不適切と判断する行為

第5条（自己責任の原則）

  1. 本アプリは家族管理を支援するツールであり、医療・法律・金融の専門助言を提供するものではありません。
  2. 体調・家計・教育に関する重要な判断は、必要に応じて医療機関・専門家にご相談ください。
  3. 本アプリの利用により生じた損害について、開発者は一切の責任を負いません。

第6条（データの取扱い）

  1. 利用者が本アプリに入力したデータは、利用者の端末内にのみ保存されます。
  2. 開発者を含む第三者は、利用者のデータにアクセスできません。
  3. 端末の故障・紛失・初期化により、データは消失する場合があります。重要なデータは利用者ご自身でバックアップしてください。
  4. 本アプリには手動でのデータ書き出し / 読み込み機能があります。定期的なバックアップを推奨します。

第7条（Hoku（AI アシスタント）の利用）

  1. 本アプリの「Hoku」は、入力された文章を端末内のキーワード判定で分類し、保存先や次の操作を提案する機能です。
  2. Hoku の応答内容は参考情報であり、医療・法律・金融上の助言ではありません。
  3. 音声入力機能は端末ブラウザの Web Speech API を利用します。対応状況は端末・ブラウザにより異なります。

第8条（プレミアム機能）

  1. プレミアム機能は将来提供予定です。
  2. 課金は App Store / Google Play の仕組みを通じて行います。
  3. 解約はお使いの App Store / Google Play アカウントの設定から行ってください。
  4. 既に提供された期間に対する返金は原則として行いません。
