01 — Executive Summary

エグゼクティブサマリー

Familink は、子育て家庭の 予定・タスク・家計・体調・準備・買い物 を、家族向け AI「Hoku」とともに一元管理する家族向けスーパーアプリです。

共働き・子育て家庭の毎日は、Google カレンダー / LINE / 紙のプリント / 家計簿アプリ / 口頭連絡 に情報が分散し、共有漏れが「朝の戦争」と夫婦間の摩擦を生んでいます。既存アプリはカレンダー特化・家計特化・メモ特化と 縦割り で、「家族運営」という横軸を担うプロダクトが存在しません。

Familink はその横軸を、8 機能の統合 + AI 入力支援 で埋めます。現在 MVP が稼働中で、自動テスト 785 件全 PASS の品質を確保。本ラウンドでは App Store 公開・実ユーザー検証・初期マーケティング検証の資金（相談ベース ¥50万〜¥300万）を求めています。

02 — Problem

解決する課題

子育て家庭は、1 日に管理する情報の種類が他の世代より圧倒的に多い。

領域現状の管理手段問題
予定Google / iPhone カレンダー（個人ごと）家族で見るのに複数アプリ
タスクLINE / 記憶誰がいつまでにが曖昧
持ち物紙のプリント / 記憶朝の忘れ物・準備漏れ
体調メモ / 記憶発熱日・薬の記録が残らない
家計別の家計簿アプリ夫婦の一方しか把握しない
買い物口頭 / メモ共有漏れ・重複購入
家庭内オペレーションは、まだ DX されていない。

03 — Solution

ソリューション

家族で使う 8 機能を 1 つのスマホアプリに統合。すべて家族メンバー単位で紐付き、「誰のために・誰がやり・いつ・いくら・何が必要か」が家族で共有されます。

機能価値
カレンダー家族の予定を集約。外部カレンダー（Google/iPhone/Yahoo）も ICS 取込対応
タスク誰が・いつまでに。完了チェックで分担を可視化
家計単発取引 + 固定収支 + 月末残高見込みで不安を減らす
体調管理体温・症状・薬を家族で記録（診断ではなく振り返り）
準備リスト曜日別の持ち物・時間割。前夜に準備を完了
買い物リスト今すぐ / 次の買い物 / よく買う の 3 階層
家族ボード共有メモ・写真・スレッド
Hoku AI一言で予定・家計・体調を整理する家族アシスタント

04 — Hoku AI

Hoku AI — 差別化の核

Hoku は、家族向け文脈に最適化した軽量 AI アシスタント。短い自然な日本語を、適切な機能へ振り分けます。

入力例反映先
「明日18時、星旺スイミング」カレンダー
「スーパーで3,200円」家計
「星汰37.8度 咳」体調管理
「明日の準備に体操服」準備リスト
「牛乳追加」買い物リスト

差別化ポイント

  • 家族向け文脈に特化（メンバー名・体温・教科・期間・全角/漢数字を理解）
  • テキスト + 音声入力（Web Speech API、追加ハード不要）
  • 会話の文脈を 5 ターン保持（「やっぱ花子で」が通じる）
  • 確認モーダル必須で誤分類しても自動保存しない安全設計
  • 医療・税務・薬の量は診断しないガードレール
  • 外部 API 不要・完全ローカル実行（プライバシー最優先）

11 — Security / Privacy

セキュリティ / プライバシー方針
  • 現 Web 版はユーザーが選択したファイル / 入力データのみを扱い、外部送信しない
  • 外部カレンダーを許可なく自動取得しない（ICS 手動取込のみ）
  • 将来のクラウド化では Row Level Security による家族単位アクセス制御を前提
  • API Secret をフロントに置かない設計（GitHub Pages 公開前提）
