# Familink アプリアイコン

## デザイン意図

- **ハート**：家族の絆。Familink の中心価値「家族をチームにする」
- **3 つの円**：家族のメンバー（親と子ども）。「3 児パパが作る家族向けアプリ」のブランドと整合
- **金の星**：AI アシスタント Hoku。家族を見守るガイド役 / プレミアム感
- **配色**：ブランドブルー（#5BA3EC → #3F82D4）+ ゴールド（#C8A95B）。`ui-ux-guideline.md` 準拠

## ファイル

- `app-icon.svg` — ベクター原本（編集はこれを修正）
- `icon-{size}.png` — 各サイズの PNG（cairosvg で SVG から書き出し）

書き出しサイズ：1024 / 512 / 256 / 180 / 167 / 152 / 144 / 120 / 114 / 100 / 87 / 80 / 76 / 72 / 60 / 58 / 57 / 40 / 29 / 20

## 用途別の主なサイズ

| 用途 | サイズ |
|---|---|
| App Store 提出（マーケティング）| 1024×1024 |
| iPhone アプリアイコン（@3x）| 180×180 |
| iPad アプリアイコン | 152 / 167 |
| Spotlight / 設定 | 80 / 87 / 58 / 120 |
| ファビコン（Web）| 32 / 64（20-60 から流用可）|

## 再書き出し方法

```bash
cd docs/assets/app-icon
python3 -c "import cairosvg; cairosvg.svg2png(url='app-icon.svg', write_to='icon-1024.png', output_width=1024, output_height=1024)"
```

## 注意

- iOS のアプリアイコンは **角丸なし・フルブリード**で提出する（OS 側が自動でマスク）
- 1024×1024 は **アルファチャンネルなし**が必須。提出時に書き出しツールで確認
- 本アイコンは草案。最終提出前にオーナーがデザインを確認・微調整すること
