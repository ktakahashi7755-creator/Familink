## v0.2（公開後 1 ヶ月）— 家族同期 + 課金実装フェーズ

### 目的
- W-1（家族 2 端末同期なし）と W-3（課金価値が文言ベース）を解消
- 「払って良かった」と感じてもらえる実体価値を作る

### 主要機能

#### F-01 家族 2 端末同期（W-1 解消、S+）
- **最小実装**：QR コード共有による「家族コード」発行 → もう一方の端末でスキャン → 同じ家族 ID で LocalStorage を同期
- **次段階**：Supabase バックエンドで家族 ID を中心にデータを共有（無料プランで 1 家族 / 5 メンバーまで）
- **設計原則**：個人を識別する情報は引き続き保存しない。家族 ID は端末内で生成された UUID

#### F-02 通知・リマインド（W-2 解消、S）
- 翌日の予定・準備リスト・体調メモのリマインド
- iOS / Android のローカル通知 API（バックエンド不要）
- 朝 7:00 に「今日の段取り」を Hoku が要約して通知

#### F-03 週次サマリー / 振り返り（プレミアム機能）
- 日曜夜に「今週の家族ハイライト」を Hoku が生成
- 家計・体調・予定・タスク完了率を 1 画面で振り返れる
- スクリーンショットして家族 LINE で共有可能（口コミ動線）

#### F-04 IAP 本実装（W-3 解消、A+）
- StoreKit 2 / Google Play Billing v6+ を WKWebView 経由で導入
- 月額 480 円 + 30 日無料トライアル
- 設定画面に「次回更新日」「キャンセル方法」「アクティブ表示」

#### F-05 オンボーディング第 2 弾
- 家族招待 → 同期確認 → 「初週ガイド」を Hoku が伴走

### 完成条件
- [ ] F-01〜F-05 実装
- [ ] β 30 家族で初週リテンション 40% 達成
- [ ] プレミアム転換率 5% 達成
- [ ] 致命バグ 0 件継続

## v1.0（公開後 3 ヶ月）— Hoku 強化 + グロースフェーズ

### 目的
- W-5（Hoku が文脈を覚えない）解消
- MAU 500 / 月額有料 50 を達成
- ユニコーン化の入口に立つ

### 主要機能

#### G-01 Hoku の文脈応答（W-5 解消、S）
- 直前 3 ターンの会話を反映した応答
- 「先週話した小児科の件、明日でしたよね？」など能動発話
- 実装方針：端末内で軽量 LLM を実行 or プライバシー配慮型 API 連携（要設計）

#### G-02 Hoku の能動発話（毎日のひとこと）
- 朝：今日の段取り
- 夜：今日の振り返り + 明日の準備
- ストリーク報告 / 連続使用日数の演出

#### G-03 多言語対応（英語 / 中国語繁体字）
- 海外子育て家庭への展開
- 北米市場テスト

#### G-04 上位プラン段階導入
- 680 円：家族メンバー無制限 + クラウドバックアップ
- 980 円：家族 AI 高度応答 + 教育系コンテンツ連携

#### G-05 SNS グロース施策
- TikTok / Instagram Reels で「3 児パパの家族 AI 開発記」連載
- App Store ストアページの A/B テスト
- TestFlight 公開コミュニティ運営

### 完成条件
- [ ] MAU 500
- [ ] 月額有料 50 件
- [ ] 北米テスト 5 家族
- [ ] App Store 評価 4.5+
