## 2. 重大リスク Top10

### #1 外部リンク `window.open` で `noopener,noreferrer` 未設定（2件）
- リスク内容: `window.open(url, '_blank')` のうち2箇所が `noopener,noreferrer` 未設定。
  - 4170 行: お問い合わせ GitHub Issues 遷移
  - 8301 行: dataUrl 別タブ表示
- 発生可能性: 低 / 影響度: 低 / 優先度: **P1**
- 推奨対応: `window.open(url, '_blank', 'noopener,noreferrer')` に統一
- 影響範囲: JS 2 行のみ

### #2 ワークスペース「共有用 / 自分用」がアクセス制御と誤解される表現
- リスク内容: バックエンド認証が未実装のため、これは端末内ローカルでの表示
  切替に過ぎない。「共有用」「自分用」「家族で共有」表現が、他端末との同期や
  権限制御があるように誤読されるリスク。
- 発生可能性: 中 / 影響度: 中 / 優先度: **P1**
- 推奨対応: スペース切替モーダルに「端末内で表示を切り替えるモードです。
  他の端末・他のご家族とは同期されません」のヒント常設
- 影響範囲: HTML 1 箇所への注釈追加

### #3 写真・書類の保存表現が長期保存と誤解される余地
- リスク内容: 「思い出をたっぷり保存できます」等のコピーがあるが、実体は
  LocalStorage 内 base64。端末初期化・ブラウザストレージ削除で消失する。
- 発生可能性: 中 / 影響度: 中 / 優先度: **P1**
- 推奨対応: アルバム・書類保管庫・プレミアム LP に「端末内に保存されます」
  「重要な写真は端末本体や写真アプリにも保管をおすすめします」の注記追加
- 影響範囲: HTML 文言追加 3 箇所程度

### #4 Hoku 応答に AI 一般免責が常設されていない
- リスク内容: 個別の医療・法律・金融免責は実装済みだが、「AI による提案で
  あり、最終判断はご家族で」の一般免責が画面常設されていない。AI 回答を
  過信して誤判断につながるリスク。
- 発生可能性: 中 / 影響度: 中 / 優先度: **P1**
- 推奨対応: Hoku 画面の入力欄付近またはヒント帯に常設一文を追加
- 影響範囲: HTML 1 箇所追加

### #5 LocalStorage データ消失リスクの常設案内不足
- リスク内容: 容量超過は通知されるが、「ブラウザの履歴/データ削除や端末
  変更で全データが消える」点の常設案内が薄い。引き継ぎ手段が現状なし。
- 発生可能性: 中 / 影響度: 高 / 優先度: **P1**
- 推奨対応: 設定画面に「データは端末内に保存。ブラウザの履歴削除や端末
  変更でデータが消える可能性があります」の注意ブロックを追加。中期的には
  エクスポート/インポート機能を提案。
- 影響範囲: 設定画面に1ブロック追加

### #6 体調記録の緊急時案内の常設度
- リスク内容: 体調画面ヘッダーに医療免責はあるが、「ぐったり・けいれん・
  高熱が続く」等の緊急時に「#7119 / 119 / 医療機関相談」を促す常設案内が
  ない。
- 発生可能性: 低 / 影響度: 高 / 優先度: **P2**
- 推奨対応: 体調画面に小さく「緊急時は #7119 や医療機関へ」の常設リンク
  または注記を追加
- 影響範囲: HTML 文言追加 1 箇所

### #7 家計画面の金融助言誤認リスク
- リスク内容: 家計サマリや「カテゴリ別上位」表示がアドバイスのように
  読まれるリスク。
- 発生可能性: 低 / 影響度: 低 / 優先度: **P2**
- 推奨対応: 家計画面の説明や設定 FAQ に「家計管理は記録支援であり、
  金融助言ではない」の一文を入れる
- 影響範囲: 文言1〜2箇所

### #8 削除/初期化系の確認導線の網羅性
- リスク内容: 主要な削除には `showConfirm` が使われている確認済みだが、
  まれに直接 `S.x = []` や `splice` 等で確認なし削除が残っている可能性。
- 発生可能性: 低 / 影響度: 中 / 優先度: **P2**
- 推奨対応: 削除パスを継続棚卸し（次セッションで grep + 個別レビュー）
- 影響範囲: 棚卸し → 必要に応じ確認モーダル追加

### #9 子ども情報の取り扱い説明の強化余地
- リスク内容: プライバシーポリシーには「子どものプライバシー」項あり。
  子ども追加 UI に保護者向け簡潔注意（保護者の責任で記録する旨）の常設は
  薄い。
- 発生可能性: 低 / 影響度: 中 / 優先度: **P2**
- 推奨対応: 子ども追加モーダルに「保護者が責任を持って管理してください」
  程度の一文
- 影響範囲: HTML 1 箇所

### #10 入力長制限・記号入力耐性の網羅性
- リスク内容: 多くの input に `maxlength` 設定済だが、`textarea` 系で
  長文/異常記号入力に対する明示的制限が薄い可能性。
- 発生可能性: 低 / 影響度: 低 / 優先度: **P3**
- 推奨対応: 主要 textarea に maxlength を継続付与
- 影響範囲: HTML 属性追加
