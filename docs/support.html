よくある質問

Q. データはどこに保存されますか？

すべてのデータはお使いの端末内（ブラウザの LocalStorage）にのみ保存されます。外部サーバーには送信されません。詳しくはプライバシーポリシーをご覧ください。

Q. 機種変更したらデータはどうなりますか？

データは端末内に保存されるため、機種変更では引き継がれません。設定画面の「データの書き出し」で事前にバックアップし、新しい端末で「読み込み」してください。

Q. データが消えてしまいました。

ブラウザの履歴・サイトデータの消去、プライベートモードの利用、ストレージ容量不足などで消えることがあります。定期的に「データの書き出し」でバックアップすることをおすすめします。

Q. Hoku（AI アシスタント）の音声入力が使えません。

音声入力は端末ブラウザの Web Speech API を利用します。対応していない端末・ブラウザでは利用できません。その場合はキーボード入力をご利用ください。

Q. 料金はかかりますか？

基本機能は無料でご利用いただけます。一部の高度な機能は将来、月額 480 円（予定）の「Familink プレミアム」として提供予定です。

Q. 家族のスマホとデータを共有できますか？

現在は端末内保存のため、自動共有は行いません。「データの書き出し / 読み込み」で手動共有が可能です。家族同期機能は今後のアップデートで検討しています。
