## 1. 修正内容

### 1.1 家族ボード（s-board）から準備リスト分離
- 上部にあった `.prep-quick-card`（準備リスト クイックサマリー）を削除
- 関連 CSS 11 ルール削除
- 家族ボードの責務 = 共有・出来事・連絡・記録 に明確化
- 準備リストは `s-prep` で独立完結（既存：今日/明日/すべてタブ + 明日に回す機能）

### 1.2 ボード作成モーダルを 7 intent 化
- 用途タイプ 3 種（準備リスト/投稿型/自由メモ）→ 7 intent
  - 💬 家族共有 / 📝 準備リスト / 🎵 習い事 / 💛 体調管理
  - 🛒 買い物メモ / 📋 提出物チェック / 📒 汎用メモ
- 大きなアイコン + ラベルの 2×4 グリッドカード
- 選択中の説明文を直下に動的表示
- health 選択時は「※ 医療判断ではなく、家族での記録としてご利用ください」注記
- ボード名プレースホルダーが intent ラベルに動的変更

### 1.3 ボード作成時の自動初期化
- `b.intent` フィールド保存（LocalStorage 構造に追加のみ・破壊なし）
- `b.type` は INTENT_META[intent].baseType から自動設定（後方互換）
- prep/shopping/submissions は自動でセクション 2 つを生成
  - prep → 今日の準備 / 明日の準備
  - shopping → 今すぐ / 次の買い物
  - submissions → 今週 / 来週以降

### 1.4 各ボード詳細（s-custom-board）の改善
- **用途ヒーロー**：アイコン + ラベル + 説明文 + 注記（先頭に表示）
- **空状態**：「下の『＋ {addBtn}』から始めましょう」+ 入力例チップ
- **追加ボタン**：固定配置（タブバー上）+ intent 別文言（「＋ 買い物を追加」など）
- 追加ボタンが押せない問題（タブバー被り）を修正

### 1.5 項目追加モーダル（m-board-item）の intent-aware 化
- タイトル入力欄プレースホルダー：intent.titlePh（例：例：牛乳 / 例：37.5度の発熱）
- モーダルタイトル：intent の addBtn そのまま
- セクション初期選択：自動生成された最初のセクション
- カテゴリ初期選択：intent.defaultCategory
- 自動フォーカスをタイトル欄に

### 1.6 ホームのカスタムボードカード
- 空状態文言を「タップして『＋ {addBtn}』」に
- ラベルバッジを intent.label に変更（buy → 買い物メモ など）

## 6. iPhone 確認ポイント

1. **家族ボード**：上部の準備リストカードが消えて、家族共有のみのシンプルな画面に
2. **ホーム → ＋ ボードを追加**：7 つの用途カード（💬💔🎵💛🛒📋📒）が表示
3. **用途を選ぶたび**：直下の説明文が動的に変わる
4. **体調管理**を選ぶと：「※ 医療判断ではなく…」注記が出る
5. **買い物メモ作成 → 詳細画面**：
   - 用途ヒーロー（🛒 買い物メモ + 説明）
   - 「まだ項目がありません」+ 入力例チップ（牛乳 / おむつ / 洗剤 / 明日の弁当材料）
   - 自動セクション「今すぐ」「次の買い物」
   - 下部固定の青いボタン「＋ 買い物を追加」
6. **追加ボタンタップ**：モーダル「買い物を追加」/ プレースホルダー「例：牛乳」
7. **保存** → 「今すぐ」セクションに項目追加される
8. 既存の家族ボード投稿 / 準備リスト / タスク / 家計データはすべて無事
