# Familink MVP 要件定義

このドキュメントは、Familink の MVP（最小公開可能版）に必須となる機能と受け入れ条件の **正本** です。
ロードマップ全体は `docs/product-roadmap.md`、UI 基準は `docs/ui-ux-guideline.md` を参照。

---

## 1. MVP のゴール

App Store / Google Play へ初回公開できる品質で、以下を満たす：

- 家族 1 ユニットが「予定共有 / タスク管理 / 家族ボード」を使い始められる
- Hoku が画面内に常駐し、最低限のナビゲートを行う
- 無料で習慣化できる土台があり、プレミアム導線（月額 480 円）が破綻なく差し込まれている
- iPhone での片手操作が成立する
- 致命バグ（S 級）ゼロ

---

## 2. MVP 必須機能

### 2.1 ログイン / 家族登録

- メールまたは簡易 ID + パスワードでログイン
- 初回起動時に家族名・メンバーを登録
- 招待は MVP では「コードコピー」程度で十分（メール送信は次フェーズ）

**受け入れ条件**
- 初回起動から 60 秒以内に家族 1 ユニットが作成できる
- 既ログイン状態が次回起動時に保持される

### 2.2 ホーム画面

- 今日 / 今週の予定とタスクを一目で把握できる
- Hoku が右下に常駐し、状況に応じた一言を添える
- 主要画面への導線（予定 / タスク / ボード / 設定）が片手で届く

**受け入れ条件**
- 起動 → ホーム描画まで 3 秒以内
- 1 タップで予定 / タスク / ボードへ遷移できる

### 2.3 予定共有

- 家族メンバー全員に共有される予定の作成・編集・削除
- 担当者（誰の予定か）を必須で指定
- 月 / 週 / 日のいずれかのビューで閲覧

**受け入れ条件**
- 予定の作成は 3 タップ以内（日付選択 + タイトル + 保存）
- LocalStorage に保存され、再起動後も残る

### 2.4 タスク管理

- 家族で共有する ToDo リスト
- 担当者・期限・完了状態を持つ
- 完了済みは自動で下に移動 or 隠せる

**受け入れ条件**
- 完了チェックが 1 タップで動作
- 期限切れタスクが視認できる（色 / バッジ）

### 2.5 家族共有ボード

- メモ・連絡事項・ちょっとしたお知らせを家族で共有
- テキストのみ（画像は次フェーズで OK）
- 投稿者名と日時が表示される

**受け入れ条件**
- 投稿 / 削除が壊れない
- 1 ボードあたり最低 50 件は安定保存できる

### 2.6 Hoku（基本導線）

詳細は `docs/hoku-guideline.md`。MVP では以下が動けば十分：

- 右下に常駐表示（消せるオプションは後回しで OK）
- 軽い浮遊・呼吸アニメ
- 状況に応じた一言（朝の挨拶 / 予定リマインド / 空状態の声かけ）

**受け入れ条件**
- 主要画面のレイアウトを Hoku が崩さない
- 文言が `docs/hoku-guideline.md` の口調ガイドに沿う

### 2.7 プレミアム制限の基礎

詳細は `docs/premium-strategy.md`。

- 「プレミアム機能」を表す印 / バッジを用意
- 無料プランでも基本機能は壊れない
- プレミアム導線（紹介 → 月額 480 円）が破綻なく出る（ダミー導線で可、決済本実装は人間確認）

**受け入れ条件**
- 無料プランで MVP 機能がすべて使える
- プレミアムバッジ表示が崩れない

### 2.8 データ保存（LocalStorage）

- 予定 / タスク / ボード / 家族情報 / 設定はすべて LocalStorage
- キー命名は `cto-architect` で管理
- 再起動・端末再読込で保持される

**受け入れ条件**
- iPhone Safari 標準動作で保持される
- 再読み込み後にホーム表示が壊れない

---

## 3. 公開品質の最低ライン

- 致命バグ（押せない / 保存されない / 閉じない / JS エラー / iPhone 操作不能）ゼロ
- 主要画面で TS / lint エラーなし
- 不要な console.log を残さない
- 余白・色・角丸の統一感（`docs/ui-ux-guideline.md`）
- App Store のスクリーンショットが撮れる状態

---

## 4. MVP に **含めない** もの

下記は Phase 2 以降。MVP では実装しない：

- 家計管理 / 体調記録 / 習い事記録 / 準備リスト
- 通知（プッシュ / メール）
- 画像投稿
- 招待機能（メール / SMS 送信）
- 高度な Hoku アニメ・対話
- アバター複数選択
- 上位プラン（680 円〜）

---

## 5. 受け入れ最終チェック

`docs/test-checklist.md` に従って、`familink-qa-lead` が手動回帰テストを通過させたら MVP 完了とみなす。
