## 4. Hoku 音声機能の改善内容（詳細）

### Before
- マイクボタン押下 → silent fail（iPhone Safari）
- フォールバックは toast のみ → 視認性低い
- onstart が呼ばれない場合の保護なし
- 失敗時にテキスト入力欄へのフォーカス案内なし

### After（Wave 14）
1. **永続バナー `#hoku-voice-status`** を入力欄の上に追加
   - `listening` 時：「🎙 聞き取り中… 話しかけてください」
   - `unsupported` 時：「音声入力はこの端末では使えないため、テキストで相談してください」
   - 状態が変わるたびに即時更新
2. **3 秒セーフティタイムアウト**
   - `start()` 後 3 秒以内に `onstart` が呼ばれなければ失敗扱い
   - `abort()` + 案内 + テキスト入力欄フォーカス
3. **失敗時の自動フォーカス**
   - 非対応 / エラー / no-speech のいずれでも `_hokuVoiceFocusInput()` でテキスト入力に誘導
4. **エラーメッセージの強化**
   - `not-allowed` → 「iPhone Safari の場合：設定 > Safari > マイク」と具体例を含む案内
   - `network` → 電波状況案内を追加
5. **空認識結果のフォローアップ**
   - 認識が成功でも text が空の場合に「もう一度お試しください」案内

### iPhone Safari での既知の制約
- iOS Safari は `webkitSpeechRecognition` を露出するが、サーバー認識は不安定
- 多くのケースで `onerror` が `network` または `service-not-allowed` を返す
- → 今回の 3 秒タイムアウト + フォールバックで「押しても何も起きない」を解消

### GitHub Pages（HTTPS）での確認ポイント
- HTTPS 必須要件は満たす
- マイク権限ポップアップが Safari 側で表示される（初回）
- 拒否時は明確な案内 + テキスト入力へ誘導
