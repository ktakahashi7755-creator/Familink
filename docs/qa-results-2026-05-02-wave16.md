## 1. 修正内容

### 1.1 ホーム右上：カメラアイコン追加（Wave 15 で空欄になっていた）
- `home-camera-btn` クラスを新設（38×38 / 角丸 12 / SVG カメラアイコン）
- onclick → `openPostModal(null)`（家族にシェア = 家族ボードへの投稿モーダル）
- title / aria-label：「家族にシェア」
- iPhone でのタップ領域確保
- ホーム全体のレイアウトに馴染むよう、家計の `.budget-nav-btn` と同じ上品なボックス調デザインに統一

### 1.2 家計画面：CSV ボタン撤廃
- ヘッダー右上の `<button onclick="exportAllCSV()">CSV</button>` を削除
- `exportAllCSV()` 関数を完全削除（12 行）
- 残骸ゼロ：grep で `exportAllCSV` / `familink_budget.csv` 0 件確認

### 1.3 家計画面：家族全体 / メンバー別 切替タブ + 集計
**新規 UI：**
- ヘッダーバー直下に水平スクロールの **メンバー切替タブ**
- 「👨‍👩‍👧‍👦 家族全体」+ MEMBERS（パパ/ママ/太郎/花子/健太）+ 「🏠 家族共通」
- 各タブに金額（その月の支出合計）を表示
- アクティブタブはプライマリ色で強調

**振る舞い：**
- 家族全体：すべての取引を集計
- 各メンバー：そのメンバーの取引のみ集計
- 家族共通：member='common' の取引（または未割当）を集計
- 切替で：ヒーローカードのタイトル / 収入 / 支出 / 収支 / 取引一覧 すべて連動

**取引追加モーダル：**
- 「担当者」選択ボタンを追加（MEMBERS 5 名 + 家族共通）
- 選択中のタブが家族全体以外なら、そのメンバーが初期選択
- 家族共通も明示的に選べる
- 既存の `t.member` フィールドをそのまま利用（LocalStorage 構造変更なし）

**取引一覧表示：**
- 担当者カラムが「家族共通」に対応（member='common' or 未割当時に「家族共通」表示）
