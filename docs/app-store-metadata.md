### 説明文（4000 字以内）
```
■ Familink — 家族みんなで子育てをチームにするアプリ

家族の予定、子どものタスク、持ち物、体調、家計、家族ボードを 1 つのアプリで管理できます。
忙しい毎日でも、家族全員で同じ情報を見て、同じ手順で動けるように設計しました。

■ 主な機能

・予定共有（カレンダー）
  家族みんなの予定を月／週／リスト表示。担当者ごとに色分けで一目で把握。

・タスク管理
  「明日までに体操着を洗う」「保育園の書類を提出」などを家族で共有。
  担当者・期限・優先度・カテゴリを設定でき、リスト表示／カンバン表示の切替も。

・持ち物・準備リスト
  学校・幼稚園・習い事の持ち物を、子どもごと・前日／朝の確認でチェック。

・体調メモ
  子どもの体温・症状・薬・受診履歴を時系列で残せます。

・家計メモ
  食費・固定費・教育費などのカテゴリ別に簡単に記録。月次サマリ表示。

・家族ボード
  日々の出来事や連絡事項を投稿。コメント・リアクション・ピン留め対応。
  カスタムボードで「買い物リスト」「我が家のルール」など自由に作成。

・書類保管庫
  学校からのプリント、領収証、写真などをフォルダ別に整理。

・Hoku — AI アシスタント
  「明日 15 時に小児科」「子どもが熱っぽい」「今月の食費が高い」など
  自然な日本語で話しかけると、Hoku が内容を理解して保存先と次の操作を提案します。
  音声入力にも対応（端末の対応状況により異なります）。

■ データ保護
  ・ゲスト利用：すべてのデータは端末内（LocalStorage）にのみ保存されます
  ・メール登録後：Supabase（米国）の安全なサーバに暗号化して保存。機種変更後も復元できます
  ・Hoku AI は端末内で動作。外部 AI サーバへのデータ送信はありません（オプション設定を除く）
  ・詳細はプライバシーポリシーをご覧ください

■ 料金
  ・無料プラン：基本機能をすべてお使いいただけます（登録不要）
  ・30日間 無料トライアル：プレミアム機能を無料でお試しいただけます（クレジットカード不要）
  ・Familink プレミアム（月額 480 円予定）：登録件数無制限・Hoku 無制限・プレミアムアバター・カスタムボード
  ※本バージョンは β 版です。正式課金は今後のアップデートで実装します

■ 対応端末
  ・iPhone：iOS 16 以降推奨
  ・iPad：iPadOS 16 以降推奨
  ・Web ブラウザ：Safari / Chrome / Edge / Firefox 最新版
```

## App Privacy（プライバシー）情報

### データ収集
- **ゲスト利用時（未登録）**：収集なし。すべてのデータは端末の LocalStorage に保存。
- **メール登録後**：以下のデータを Supabase（米国）に保存。Row Level Security で保護。

### データの種類
| 種類 | ゲスト | 登録後 | 使用目的 |
|---|---|---|---|
| 連絡先情報（メールアドレス）| ❌ | ✅（認証用）| アカウント識別・ログイン |
| 健康・フィットネス（体調データ）| ❌ | ✅（暗号化）| 家族の体調記録機能 |
| 財務情報（家計データ）| ❌ | ✅（暗号化）| 家計管理機能 |
| 位置情報 | ❌ | ❌ | — |
| ユーザーコンテンツ（予定・投稿等）| ❌ | ✅（暗号化）| アプリ機能 |
| 識別子（user_id）| ❌ | ✅（内部）| データ紐付け |
| 使用状況データ | ❌ | ❌ | — |
| 診断情報 | ❌ | ❌ | — |

※登録したデータは「設定 → アカウントを削除」から完全削除できます

### 子供のプライバシー
- 13 歳未満を対象としていない（家族の保護者向け）
- ただし家族内で子どもの情報を保護者が記録する用途あり
- COPPA 対応：データ収集なし

## App Store Review 情報

### デモアカウント
- **不要**：デモデータボタンで誰でも体験可能
- ログイン画面の「デモデータで試してみる」ボタンを案内

### レビュー用メモ
```
Familink は、家族向けの予定・タスク・家計・体調・家族ボード・持ち物管理アプリです。
メール登録なしでゲストとして利用できます。
登録した場合は Supabase（米国）にデータが保存されます。

レビュー手順：
1. アプリ起動後、「ゲストとして続ける」をタップ（登録不要）
2. 家庭向けリアルデモデータが自動で入っています
3. ホームから各機能をご確認ください
4. Hoku 画面で「明日15時に小児科」「今日の予定を教えて」など話しかけてみてください
5. 設定 → アカウントを削除 からデータ削除できます（App Storeガイドライン対応）

プレミアム機能：
- 「30日間 無料でためす」から β トライアル開始（課金処理なし）
- 本バージョンは β 版のため、実際の課金は発生しません
- 正式リリース後に App Store IAP を通じて実装予定
```
