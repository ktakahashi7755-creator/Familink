# Familink iPhone 実機 QA ガイド

このドキュメントは、PC ローカルで Familink を起動し、**iPhone（または Android）の実機で動作確認**するための手順書です。
プログラミングに詳しくない方でも進められるよう、コマンドや確認項目を細かく記載しています。

---

## 1. このガイドでやること

1. PC で静的サーバを立てる（依存ライブラリ不要、Python 標準機能だけ使用）
2. 同じ Wi-Fi に繋がった iPhone から PC のサーバへアクセス
3. **21 画面 + 第 1 弾修正の検証項目** をチェックリスト方式で確認
4. 発見したバグや UI 崩れを **バグ報告テンプレート** に記録

詳細な静的 QA 結果は `docs/qa-findings-2026-05-01.md` を参照してください。

---

## 2. 必要なもの

- PC（macOS / Windows / Linux のどれでも OK）
- Python 3 がインストール済み（macOS / Linux は標準で入っていることが多い）
  - 確認方法：ターミナル / コマンドプロンプトで `python3 --version` と入力 → `Python 3.x.x` と出れば OK
  - Windows で入っていない場合：[python.org](https://www.python.org/downloads/) から無料で入手
- iPhone（iOS Safari 推奨）または Android スマホ
- **PC とスマホが同じ Wi-Fi ネットワークに接続されていること**

---

## 3. PC でサーバを起動する手順

### 3-1. ターミナルを開く

| OS | 開き方 |
|---|---|
| macOS | アプリケーション → ユーティリティ → ターミナル |
| Windows | スタート → "PowerShell" または "コマンドプロンプト" |
| Linux | Ctrl+Alt+T |

### 3-2. リポジトリの場所に移動

ターミナルに以下を入力（`/path/to/Familink` は実際のクローン場所に置き換え）：

```bash
cd /path/to/Familink
```

迷ったら `pwd`（macOS/Linux）/ `cd`（Windows）で現在地を確認できます。

### 3-3. サーバを起動

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

> Windows で `python3` コマンドが効かない場合は `python -m http.server 8000 --bind 0.0.0.0` を試してください。

成功すると以下のような表示になります：

```
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

**この画面はサーバ動作中なのでターミナルを閉じないでください。** 終了するときは `Ctrl+C` を押します。

### 3-4. PC のローカル IP アドレスを調べる

iPhone から PC にアクセスするために、PC の IP アドレスが必要です。

| OS | コマンド |
|---|---|
| macOS | `ipconfig getifaddr en0`（Wi-Fi 経由）。出ない場合 `ifconfig | grep "inet "` |
| Windows | `ipconfig` を実行し「IPv4 アドレス」の値（例：`192.168.1.10`）を確認 |
| Linux | `hostname -I`（先頭の値） |

返ってきた値（例：`192.168.1.10`）が **PC の IP アドレス** です。`127.0.0.1` や `localhost` ではない値を使ってください。

## 4. iPhone からアクセスする

### 4-1. Safari で URL を入力

iPhone Safari のアドレスバーに：

```
http://192.168.1.10:8000/src/familink.html
```

（`192.168.1.10` は手順 3-4 で確認した値に置き換える）

正常に開けば Familink のウェルカム画面（紫系のヒーロー画像 + 「Familink」「家族みんなでつながる」）が表示されます。

### 4-2. うまくアクセスできない場合のチェック

| 症状 | 確認 |
|---|---|
| 「サーバが見つかりません」 | PC とスマホが同じ Wi-Fi か / IP アドレスを正しく入力しているか |
| ページが真っ白 | URL が `http://`（`https://` ではない）か、ポート `:8000` を含んでいるか |
| 接続タイムアウト | PC のファイアウォールがブロックしている可能性。一時的に許可するか、別ポート（例：`8080`）で起動 |
| 別の家族が PC を再起動した | IP アドレスは Wi-Fi 再接続で変わることがある。手順 3-4 を再実行 |

### 4-3. ホーム画面に追加（PWA 風起動）

実際の使い勝手を再現するため、Safari の共有ボタン → 「ホーム画面に追加」で起動するのを推奨。
（`apple-mobile-web-app-capable=yes` が指定済みのため、フルスクリーンでネイティブアプリ風に開きます）

## 7. iPhone 実機ならではの確認観点

以下は静的解析では絶対に判定できないので、実機で必ず触ってください。

```text
[セーフエリア]
[ ] ノッチ（画面上の出っ張り）にヘッダーがかぶっていない
[ ] ホームインジケータ（画面下のバー）に主要ボタンがかぶっていない
[ ] 横向きにした時に崩れない（または横向きが禁止されている）

[Hoku FAB]
[ ] 画面右下に Hoku アイコンが常駐している
[ ] 軽くドラッグで位置移動できる
[ ] 一度移動した位置がアプリ再起動後も保持される
[ ] タップで Hoku 画面に遷移する
[ ] 主要操作ボタン（FAB予定追加 等）と重ならない

[キーボード]
[ ] 入力欄をタップしてキーボードが出る時、保存ボタンが隠れない
[ ] キーボードを閉じた後にレイアウトが崩れない

[タッチ操作]
[ ] スクロールがスムーズ
[ ] タップ領域が小さすぎない（指で確実に押せる）
[ ] タスクの長押しドラッグ＆ドロップが動作する
[ ] モーダル背景タップで閉じられる（プレミアムゲート / 削除確認は除外）

[LocalStorage 復元]
[ ] 予定 / タスク / 投稿 / 取引を作って Safari を一度閉じる
[ ] 再度開いた時にデータが残っている
[ ] ホームに追加したアプリ起動でも残っている
```
