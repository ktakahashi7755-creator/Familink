# 04. 画面設計（全画面カタログ）

## 4.1 画面一覧（screen id）
`.screen` 要素として実装。表示は `go(id)` / `switchTab(id)` / `refresh(id)`。下部タブは5つ（ホーム/やること/カレンダー/家計/ボード）。

| id | 名称 | 種別 | 主な内容 |
|---|---|---|---|
| `s-ob` | ウェルカム/ログイン | 入口 | ブランドヒーロー＋メール/パスワードログイン・新規登録・パスワード再設定・Google/Apple・ゲスト |
| `s-onboard` | オンボーディング | 入口 | 初回プロフィール/家族設定 |
| `s-login` | ログイン（旧・ローカル） | 入口 | 端末内アカウントの互換導線 |
| `s-home` | ホーム | タブ | 家族ボード/やること/今週の予定/体調/お知らせメモ等のカード集約・共有状態バナー |
| `s-task` | やること | タブ | タスク一覧・フィルタ（すべて/今日/今週/期限切れ/完了）・メンバー別 |
| `s-cal` | カレンダー | タブ | 月/週/リスト・メンバーフィルタ・予定一覧・OCR取込・＋追加 |
| `s-budget` | かんたん家計 | タブ | 月次収支・カテゴリ内訳・固定収支/資金繰り |
| `s-board` | 家族ボード | タブ | お知らせ/投稿・ピン/コメント/リアクション・カスタムボード入口 |
| `s-health` | 体調・成長 | 詳細 | 子ども別の体温/症状/服薬/受診記録・推移・医療注記 |
| `s-prep` | 準備リスト | 詳細 | 学校/習い事/病院等の持ち物・曜日ルーティン |
| `s-shopping` | 買い物 | 詳細 | 今すぐ/次の買い物・数量・購入済み・よく買うもの |
| `s-hoku` | Hoku（AI） | 詳細 | 会話・サジェスト・残回数・音声入力・エージェント実行 |
| `s-album` | アルバム | 詳細 | 家族写真（遅延読み込み・容量管理） |
| `s-memo` | メモ | 詳細 | 共有メモ・フォルダ |
| `s-notif` | 通知 | 詳細 | お知らせ一覧（空状態あり） |
| `s-settings` | 設定 | 詳細 | 家族/メンバー/アバター/テーマ/ストレージ/通知設定/クラウド/法的文書/FAQ/解約 |
| `s-premium` | プレミアム | 詳細 | 特典比較・トライアル・登録/お支払い管理（Stripe有効時） |
| `s-board-detail` / `s-custom-board` | ボード詳細/カスタムボード | 詳細 | 個別ボードの項目/セクション |
| `s-ch` / `s-cdetail` | チャンネル/詳細 | 詳細 | 共有チャンネル系（表示モード） |
| `s-archive` | 書類保管庫 | 撤廃 | **UIから撤去済**（到達不可・旧データ整理のみ） |

## 4.2 画面共通仕様
- **ヘッダー**：日付・共有状態バッジ・ファミコイン残高・通知ベル（バッジ件数）。
- **スクロール領域**：`.scroll-area` / `.home-board-scroll`。同期由来の再描画はスクロール位置を保存→復元（チラつき防止）。
- **モーダル**：`.modal-backdrop`（`.open` で表示）。87種。開閉は `openModal/closeModal`。グリップ＋角丸のボトムシート調。
- **空状態**：温かい文言（「まだ〜ありません」）＋次の一手（例「右下の ＋ から登録できます」）。
- **エラー境界**：画面描画で例外が出ても白画面にせず、画面内オーバーレイ「もう一度試す/ホームに戻る」。
- **FAB/常駐 Hoku**：主要画面の右下に Hoku フローティング（ドラッグ移動可・タップで s-hoku）。

## 4.3 遷移の骨子
```
起動 → (loggedIn?) → s-home（タブ群）
                    ↘ 未ログイン/未オンボード → s-ob → (登録/ログイン/ゲスト) → s-onboard? → s-home
招待リンク(?join=) → 捕捉して保留 → ログイン後に自動参加 → 家族同期
タブ: s-home ⇄ s-task ⇄ s-cal ⇄ s-budget ⇄ s-board
各カード/ボタン → 対応詳細画面（s-health/s-prep/s-shopping/s-hoku/s-album/s-memo/s-notif/s-settings/s-premium）
```

## 4.4 主要モーダル（抜粋）
- 予定: `m-event`（通知・繰り返し・終了日・色・メンバー）/ OCR: `m-ocr-intro/preview/loading/review/edit/prep/fail`
- タスク: `m-task-edit` / 家計: 取引モーダル / 体調: 体調入力・編集
- 家族: `m-my-invite`（招待リンク）/ `m-supa-invite`（コード参加）/ `m-supa-auth`（認証）
- 課金: `m-premium-gate` / `m-upgrade-overlay` / `m-cancel-premium`
- 通知設定: `m-notif-settings`（種別ON/OFF＋OS通知＋Web Push）
- ショップ: `m-shop`（ファミコイン/着せ替え）/ ログインボーナス: `m-login-bonus`
- 法的: `m-legal`（利用規約/プライバシー）

## 4.5 レスポンシブ/アクセシビリティ
- iPhone SE(375px)で横スクロールを出さない（長文は `word-break/overflow-wrap`）。
- タップ領域44px以上。`:focus-visible` で可視フォーカス。`prefers-reduced-motion` で常駐モーションを停止。
- 画像は意味あるものに alt、装飾は `alt=""`＋`onerror` で崩れ防止。
