# 01. 要件定義書

記法：要件IDは `FR-<領域>-<番号>`（機能要件）/ `NFR-<番号>`（非機能要件）。
各機能要件に「受け入れ条件（AC）」を付す。優先度は S(致命/必須) > A(公開前必須) > B(公開後) > C(将来)。

---

## 2. 非機能要件（Non-Functional Requirements）

| ID | 分類 | 要件 |
|---|---|---|
| NFR-01 | 構成 | 単一HTML（`app-source/familink.html`）/ Vanilla JS・CSS / ビルドなし / npm依存ゼロ。CDNは Supabase・Google Fonts のみ |
| NFR-02 | 配信 | PWA（`docs/index.html`＋`docs/sw.js` cache-first）。即時起動・オフライン動作・自動更新（版一致で検知） |
| NFR-03 | 保存 | LocalStorage 主キー `familink_v3`（写真はbase64）。容量超過は握りつぶさず通知＋ロールバック |
| NFR-04 | 対応 | iPhone Safari 中心・片手操作前提。iPhone SE(375px)で横スクロールを出さない |
| NFR-05 | 性能 | cache-first で初回以降は即時表示。画像は遅延読み込み。主要操作で体感待ちを出さない |
| NFR-06 | 可用性 | オフラインでもローカルで全機能動作。クラウドは任意 |
| NFR-07 | アクセシビリティ | タップ44px以上・reduced-motion対応・aria-label・:focus-visible・コントラスト配慮 |
| NFR-08 | セキュリティ | 家族間分離（RLS）・H()でXSS防止・秘密鍵非搭載・サーバ権利正本（§06） |
| NFR-09 | プライバシー | トラッキング/広告SDKなし・端末内優先・同意ベース・13歳未満本人利用を想定しない |
| NFR-10 | 国際化 | 日本語主。日付/金額はJST/円。将来i18n拡張余地を残す |
| NFR-11 | 品質 | QA自動84件＋ツール31スイートを常時緑。コミット前に確認 |
| NFR-12 | 保守 | app-source⇄docs同期義務（版一致）・worklog追記・CLAUDE.md準拠 |

## 3. 受け入れ基準（リリースゲート）
1. `node qa_full_test.js` が **84/84 PASS**（コンソールエラー0）。
2. tools 全スイート緑（同期マージ22件・OCR・課金・カレンダー・通知等）。
3. 全画面 pageerror 0・壊れ画像0・横スクロール0（iPhone SE幅）。
4. セキュリティ：家族分離テスト合格・XSSエスケープ確認・秘密情報の混入0。
5. app-source⇄docs 本体一致・`var V`＝`SW_VERSION` 一致。
