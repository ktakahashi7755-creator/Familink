# Familink 完全仕様書（Spec v3 / 再構築用）

対象バージョン：**v20260615j**（この一式だけで、ゼロから Familink を再構築できることを目的とする）
発行：ITS合同会社 ／ 種別：プロダクト要件定義・基本設計・運用設計の統合ドキュメント

> 本セットは「もし全コードが失われても、これを読めば同等品質で作り直せる」水準を狙った実装非依存の仕様書である。

> 技術選定を差し替えても成立するよう、**要求（What/Why）と設計（How）を分離**して記述する。
