# Familink — IAP（課金）統合計画書

**最終更新日：2026-05-02**
**ステータス：MVP v0.1 では実装しない（公開後に段階導入）**

---

## 1. 全体方針

### 1.1 MVP v0.1（現在）
- プレミアム導線・ゲート UI は **実装済み**（コミット c701025）
- 課金処理は **モックのみ**（`activatePremiumDemo()` で `S.isPremiumUser = true` をセット）
- 実 IAP は提供しない、UI と価値訴求のみ完成
- ユーザーには「機能準備中」として案内

### 1.2 MVP v0.2 → v1.0（公開後 1〜3 ヶ月）
- App Store / Google Play の課金 SDK を導入
- 1 つの月額プラン（Familink プレミアム 月額 480 円）
- 30 日間の無料トライアル

### 1.3 中長期（v1.x 以降）
- 上位プラン段階導入（680 / 780 / 980 円）
- 家族複数登録、クラウドバックアップ等を上位プランに

## 3. 技術的アプローチ

### 3.1 Web 版（GitHub Pages 公開版）
- Web 版は **無料** で全機能を公開（広告も付けない）
- 本アプリの「世界観」「触り心地」を体験してもらう場と位置付け
- iOS/Android アプリ版に誘導

### 3.2 iOS 版
- **StoreKit 2** を採用（iOS 15 以降）
- 自動更新サブスクリプション（auto-renewable subscription）
- 30 日間の無料トライアル
- 価格 Tier：日本 480 円 / 米国 $3.99 / その他主要市場で同等
- App Store Connect で In-App Purchase 設定

実装ポイント：
```swift
// 本アプリは現状 HTML 単一ファイルのため、
// iOS 版を出す場合は WKWebView ベースの薄いラッパーアプリを作成し、
// StoreKit 結果を JS bridge で HTML 側に通知する設計を想定
```

### 3.3 Android 版
- **Google Play Billing Library v6+** を採用
- 同等のサブスクリプション設定
- 価格 Tier：日本 480 円

### 3.4 Web 版でのプレミアム
- **当面は Web 版でプレミアムは販売しない**（手数料なしの利点はあるが、複雑度が増すため）
- 将来 Stripe 等を検討

## 4. 実装ステップ（公開後）

### Step 1：iOS 薄ラッパーアプリ作成
- WKWebView でローカル `index.html` をロード
- ネイティブ → JS bridge を実装
- StoreKit 連携

### Step 2：App Store Connect 設定
- IAP プロダクト ID：`familink_premium_monthly_480`
- サブスクリプション期間：1 ヶ月
- 無料トライアル：30 日
- 自動更新：有効

### Step 3：プレミアム判定の修正
現在のコード：
```js
S.isPremiumUser = true;  // モック
saveS();
```

将来：
```js
// JS bridge 経由で StoreKit から状態取得
window.familinkBridge.getPremiumStatus().then(isPremium => {
  S.isPremiumUser = isPremium;
  S.premiumExpiresAt = ...;
  saveS();
});
```

### Step 4：レシート検証
- App Store の receipt 検証 API を使用
- 当方は独自バックエンドを持たない方針のため、**iOS 側のローカル検証** で運用
- 不正対策が必要になった段階でサーバ検証を検討

### Step 5：UI 反映
- プレミアム判定が `true` の場合：
  - プレミアム機能のロックを解除
  - 設定画面に「プレミアムアクティブ」「次回更新日」表示
  - キャンセルは App Store のサブスク管理画面へ誘導

## 5. 既存コードへの影響範囲

## 6. 想定リスクと対策

| リスク | 対策 |
|---|---|
| App Store Review でリジェクト | プレミアム機能の説明を Review Notes に明記、デモアカウント不要を明記 |
| サブスク誤解約 | キャンセル方法を設定画面に明記 + 各プレミアム機能内にリンク |

| 返金請求 | 7 日以内なら App Store 規約に従う |

## 7. 法的・税務考慮

- 個人事業主としての確定申告：必要に応じて税理士相談
