## 実機確認で見るべきポイント

1. ホーム右上：カメラアイコンが「グレー枠線の角丸ボックス」として上品に見えるか
2. ホーム右上：カメラタップで投稿モーダルが開き、入力後に家族ボードに反映されるか
3. 家計：CSV ボタンが消え、ヘッダーが整って見えるか
4. 家計：メンバータブが水平スクロール可能で、押すと **必ず反応** するか（旧 UX バグ解消の確認）
5. 家計：タブ切替で「タイトル / 収支 / 一覧」が一瞬で連動するか
6. 家計：＋ ボタン → 取引追加モーダル → 「担当者」選択肢（家族共通含む）が押せるか
7. 家計：「家族全体」タブに月合計が見えるか（家族運営アプリとして最低限の要件）
8. 取引保存後にリロードしても担当者情報が維持されているか
